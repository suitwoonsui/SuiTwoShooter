# SuiTwo Game Contracts

Smart contracts for the SuiTwo shooter game on Sui blockchain.

## Quick Start

### Deploy Contracts

```bash
npm install
node deploy.js
```

That's it! See `DEPLOYMENT.md` for details.

## Important Files

- **`deploy.js`** - Complete deployment script (use this one)
- **`DEPLOYMENT.md`** - Complete deployment guide (read this)
- **`DEPLOYMENT_IDS.md`** - Source of truth for all contract IDs

## Contract Modules

- `score_submission` - Game score submission system
- `premium_store` - Premium store/inventory
- `badge_system` - Badge NFT system
- `game_pass` - Game pass system
- `tournaments` - Tournament system
