# SuiTwo Ecosystem Docs

Ecosystem-level documentation (spans multiple apps like shooter-game, the PFP builder, and the foundry).

## Pitch layers

| File | Role |
|------|------|
| **SUITWO_ECOSYSTEM_MASTER_PITCH.md** | Full-depth ecosystem script (“Spaces” / complete version) |
| **SUITWO_ECOSYSTEM_ONE_LINER_PITCH.md** | Tightest single-line (or few-line) version |
| **SUITWO_ECOSYSTEM_SHORT_PITCH.md** | Compressed pitch (~30–90s) for time-boxed contexts |
| **SUITWO_ECOSYSTEM_DELIVERY_PITCH.md** | Layer 3 delivery script (~3–7 min): modular beats for live talks |

**Word:** Sibling `.docx` files live next to each pitch `.md` in this folder (Pandoc). Regenerate after edits, e.g. `pandoc -f markdown -t docx -o SUITWO_ECOSYSTEM_MASTER_PITCH.docx SUITWO_ECOSYSTEM_MASTER_PITCH.md`.
